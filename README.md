🎓 Udemy Clone Website
A simple Udemy Clone Website created using HTML and CSS.
This project is designed as a front-end practice project to recreate the look and feel of an online learning platform.
🚀 Project Overview
This Udemy clone contains a single-page layout inspired by the Udemy website. It focuses on creating a clean and responsive user interface using only HTML and CSS.
✨ Features
🏠 Home page layout
🔍 Search bar
📚 Course categories
🎓 Course cards
👨‍🏫 Instructor/course information
⭐ Course ratings
💰 Course pricing section
📱 Responsive design
🎨 Clean and simple UI
🛠️ Technologies Used
HTML5
CSS3

Udemy-Clone/

How to run
Open the project folder.
Open index.html in your browser.
That's it! 🎉
